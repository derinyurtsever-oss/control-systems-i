How to run this
  1. Play it as it is. Same pendulum, same 15° start, the only difference is the sign of g/l. On the left it rings down; on the right it is off the chart within a couple of seconds.
    "Everything about the future is already sitting in A."
  2. Point at the eigenvalues. Left: a complex pair with negative real part — an oscillation that decays. Right: one eigenvalue is positive, and one diverging term is enough.
  3. Turn the friction to zero. The left side keeps swinging forever: Re(λ) = 0, neither growing nor decaying. The right side does not care.
  4. Pulse input, then Split. Kick both pendulums at t = 0. The full response (blue) is the initial-condition response (green) plus the forced response (red) — page 2, live.
    "We can solve the start and the input separately, because the system is linear."

Both are the linear models, 2.5 m rope, m = 1 kg. Keys: space play / pause · R restart · P pulse · S split · 0 friction off · ←/→ start angle.
