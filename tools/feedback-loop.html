Run sheet — three rounds, about 20 minutes
  1. Open loop. Press C to cut the sensor wire, then hit G twice and keep pressing space. The altitude wanders off and never comes back.
    "Nothing in this picture knows anything has gone wrong."
  2. Closed loop. Press C again to reconnect. Same gusts. The sensor catches them and the number returns to the reference.
    "What, exactly, saved it?" — the sensor wire. The feedback.
  3. The chaos round. Press 2, then 3. The controller now over-reacts to the same error. It overshoots, flips past the target, and never settles.
    "More feedback is not automatically better. React too hard and you shake the system apart."

Before each round lands, ask the room to call it: up or down? The value only appears when the packet arrives, so silence still resolves a second later. Press ↑ / ↓ mid-run to move the reference and show it tracking.
