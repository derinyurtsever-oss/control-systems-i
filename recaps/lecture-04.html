Time response

✨AI-generated recap — check anything important against the slides

You get back to a mountain cabin at 3 °C and turn the heater up to 5. The whole lecture is the answer to one question: what happens next — and how to read it off the matrix A without solving anything.

The cabin, worked through

  • The model is ẋ = −2x + 6u, with time in hours. Start at x₀ = 3, heater set to u = 5.
  • Leave the heater off and the room just cools: 3e−2t. That is the initial-condition response.
  • Start from 0 °C with the heater on: 15(1 − e−2t). That is the forced response.
  • Add them: y(t) = 15 − 12e−2t. It climbs from 3 °C to 15 °C, and it is done in about two hours.

Why you are allowed to split it

  • Linearity lets you solve the starting state and the input separately and add the answers.
  • Causality means the whole past is packed into the state at t = 0, so the history never has to be looked at again.
  • Time-invariance means you can always call "now" t = 0.
  • In general: x(t) = eAtx₀ + ∫ eA(t−τ)Bu(τ) dτ. The first term is the system's own dynamics, the second is what the input drives.

The matrix exponential

  • eAt = I + At + (At)²/2! + … — defined so that its derivative is A·eAt, just as for a scalar.
  • You will never compute it by hand. In MATLAB it is expm(A*t) — with the m; plain exp does something else entirely.
  • For analysis, change coordinates until A is diagonal (or Jordan form). The response does not change, and the exponential of a diagonal matrix is just eλt down the diagonal.

Every response is built from four kinds of term

Real λ

eλt — a plain exponential that dies away, or grows if λ is positive.

Complex σ ± jω

eσt sin(ωt + φ) — oscillation inside an envelope that decays or grows.

Repeated λ

tm eλt — from a Jordan block. With λ = 0 these are plain polynomials.

The input

Plus the input itself and its derivatives, carried through by the forced response.

Reading the response straight off the eigenvalues

  • A real eigenvalue gives a time constant τ = 1/|λ|, and its term is gone after about 4τ. The cabin has λ = −2 per hour: τ is half an hour, done in two.
  • A complex pair rings about N ≈ 0.6 · ω/|σ| times before it settles.
  • So the ratio of imaginary to real part decides how oscillatory it looks: −1 ± 10j rings about six times, −10 ± 10j barely completes one swing. That ratio comes back later as the damping ratio ζ.

Stability, three ways

  • Lyapunov stable: start anywhere bounded with no input, and the state stays bounded.
  • Asymptotically stable: it also returns to zero.
  • BIBO stable: any bounded input gives a bounded output. For minimal LTI systems this is the same as asymptotic stability.
  • The test is the eigenvalues of A. All real parts < 0: asymptotically stable. Real parts ≤ 0: Lyapunov stable, provided no eigenvalue on the imaginary axis sits in a larger Jordan block, since that is what creates a growing tm term.

If you keep one thing

The eigenvalues of A already tell you the shape of every response the system can produce. The real part is how fast a term dies away — or grows. The imaginary part is how fast it rings. Stability is just the sign of the real parts.

Worth doing this week

  • Read Åström & Murray, chapters 4–5.
  • Redo the cabin with the heater on 2 instead of 5. Before calculating, say where it ends up and how long it takes — then check.
  • Take a few 2×2 A matrices, find the eigenvalues, and sketch the response shape before running expm to see if you were right.
